# 표현·구조 훈련

파워토익 VOCA와 퀵스타트의 문제를 교재 구분 없이 학습 목표에 따라 모으는 메뉴입니다. 기존 주소와 기록 저장 공간은 유지합니다. `index.html`, `styles.css`, `questions.js`, `quickstart.js`, `practice-options.js`, `practice-options-hard.js`, `memory-practice.js`, `taxonomy.js`, `app.js`는 같은 폴더에 보관하세요.

[계정 동기화가 연결된 사이트에서 열기](https://wjfl44444-lab.github.io/toeic-study/power-voca/). 파일로 보관할 때는 `sync-model.js`도 같은 폴더에 두세요.

## 학습 범위

사용자가 제공한 「박혜원 파워토익 VOCA」의 STEP 1~30, 번호 0001~1015 전체와 아래 퀵스타트 지정 범위를 반영했습니다. 인쇄된 학습 내용만 사용하며, 손글씨 필기는 제외했습니다.

- 표제어: 1,015개
- 추가 표현: 693개
- 다의어·품사를 나눈 학습 대상: 총 2,001개
- 기존 VOCA 카드: 2,282개, 선택 단계 총 3,475개
- 퀵스타트 추가 카드: 741개, 선택 단계 총 838개
- 누락 쓰임 보완: 17개 카드, 선택 단계 17개
- 합계: 3,040개 카드, 4,330개 선택 단계(두 단계 카드 1,290개)

퀵스타트는 책 쪽수 기준 102, 105, 110~112, 114, 121~122, 130~132, 139~141, 146~151, 157, 163~168, 179, 185~187, 192~216쪽의 지정 목록·학습 구조를 반영했습니다. PDF는 표지 때문에 책 쪽수보다 1쪽 뒤에 있습니다. RC 연습 전용 196·201·206·211쪽은 이미 나온 어휘의 반복 연습으로 구분하며 새 어휘 목록으로 중복 집계하지 않습니다. 185~187쪽은 요청한 비교 강조·도치 내용과 관련 연습만 반영하며, 그 밖의 모든 비교 연습을 새 범위로 확장하지 않습니다. 지정한 범위 밖의 교재 전체를 추가한 것은 아닙니다.

2026-10-23에는 185쪽의 비교급·최상급·원급 강조 20문제와 185쪽 하단~187쪽의 도치 18문제를 추가했습니다. 각각 ‘어형·수식 → 비교급·최상급·원급 강조’, ‘문형·구조 → 도치’에서 고릅니다. 이후 암기 연습판에서는 단순 비교 형태·어순 선택보다 어떤 강조어·도치 유발 표현을 쓰는지 직접 회상하도록 개선했습니다. 기존 퀵스타트 741문제의 객체와 서명은 전부 보존합니다.

같은 표현과 같은 학습 목표가 있는 기존 카드 232개에는 퀵스타트 출처를 연결했습니다. 같은 단어라도 가산성, 목적어·보어, to V/V-ing 같은 다른 구조를 학습하는 경우에는 새 문제를 만듭니다. 해설에 교재의 책 쪽수를 표시하고, 겹치는 카드에는 함께 학습할 퀵스타트 쪽수도 표시합니다. 문제 문장과 오답은 인쇄된 학습 내용을 연습하도록 새로 구성한 응용 예문입니다.

같은 표제어도 뜻·품사·유사 표현에 따라 여러 카드가 될 수 있으므로 카드 수와 단어 수는 다릅니다. 문맥이 필요한 다의어에는 새 예문과 해석을 넣었습니다. 일부 결합 문제는 문장 대신 표현이나 문법 패턴 자체를 완성합니다. 형용사·부사나 동사의 목적어 구조를 구별하는 어형 복습도 포함됩니다.

## 사용 방법

1. 큰 분류와 세부 범위를 고른 뒤 20·50·100문제 또는 전체 문제를 선택합니다. 현재 등록되지 않은 세부 범위는 0문제로 표시하며 시작할 수 없습니다.
2. 표현 결합은 표현 완성 → 뜻, 유사 표현은 뜻 → 유사 표현 순서로 풉니다.
3. 두 단계 문제의 첫 답은 ‘답 확인’을 눌러 확인합니다. 틀리면 그 문제를 바로 오답 처리하고 해설을 보여줍니다. 맞히면 두 번째 단계로 넘어갑니다. 표현 결합 문제에서는 완성된 영어 표현을 보고 뜻을 고릅니다.
4. 채점 후 큰 글씨로 완성 표현과 뜻을 먼저 보여주고, 그 아래에 단계별 해석·선택지 설명을 제공합니다.
5. 새로고침하면 시작 화면이 열립니다. 저장된 풀이의 ‘이어서 풀기’를 누르면 선택지 순서와 선택한 답까지 복원합니다.

첫 단계에서 종료한 문제의 두 번째 단계는 ‘미진행’으로 표시하며, 추가 오답이나 채점 횟수로 세지 않습니다. 뜻 선택지는 같은 품사·문장형끼리 비교하도록 구성하고, 결합 표현은 가능한 경우 공통된 명사·내용의 해석을 유지한 채 다른 부분을 비교합니다.

개선된 문제는 새 연습부터 적용됩니다. 암기 연습판을 불러온 경우, 모든 저장된 풀이는 아직 답하지 않은 풀이까지도 원래 버전의 문장·보기·해설로 복원합니다. 이전 풀이에서도 첫 단계 오답 시 즉시 종료하는 진행 방식은 적용됩니다. 원본 문제와 누적 기록은 유지하고, 새 연습의 문제 버전을 별도로 저장합니다.

유지보수 시 게시된 선택지 버전의 내용은 바꾸지 않습니다. 이후 선택지를 수정하려면 새 버전을 부여하고 이전 버전의 선택지도 보존해야 이미 선택한 답의 의미가 바뀌지 않습니다.

영어 보기 개선판(`20261019-hard2`)은 교재에 나오는 짝표현·유사 표현을 기준으로 답을 고릅니다. 기존 문제 문장은 유지하고, 같은 품사와 비슷한 표현 구조 안에서 정답을 구별하도록 보기를 구성합니다. 다른 보기가 모든 문맥에서 문법적으로 불가능하다는 뜻은 아닙니다. 반복되던 자동사 묶음이나, 명사구와 단독 형용사·동사구를 섞어 정답 형태가 드러나는 오답을 교체합니다.

기존 `20261019-linked1`, `20261019-hard2` 선택지 파일은 그대로 보존합니다. 저장된 풀이는 이전 버전으로 계속 복원하고, 새 연습은 `20261023-memory3` 암기 연습판을 사용합니다.

## 단어별 쓰임 암기 연습판

학습 목표는 이미 아는 문법을 다시 분석하는 것이 아니라 **어떤 단어가 그 구조·결합으로 쓰이는지 외우는 것**입니다. 기존에 목적에 맞는 전치사·짝표현·유의어 문제는 유지합니다. 문법만 알면 풀리던 일부 문제와 문형 범위의 뜻 전용 문제를 새 출제 방식으로 바꿉니다.

기존 258카드의 289단계를 개선했습니다(VOCA 163카드, 퀵스타트 95카드). 인쇄 36~37·103·115·123쪽의 own 결합, be/have yet to V, 형용사 + enough, call/elect + 목적어 + 명사, 요청·제안과 응답 표현 17카드를 보완했습니다. 기존 3,023개 원본 객체와 이전 보기 파일은 그대로입니다.

- 문형: 단어를 보고 허용되는 구조 선택 / 구조를 보고 들어갈 단어 선택. 일반 that절은 that 자체보다 that절을 직접 받는 동사를 확인합니다.
- 결합: 특정 전치사·짝단어를 완성하고, 필요한 경우 다음 단계에서 뜻을 고릅니다.
- 비교·도치: 단순 어순·품사 대신 강조어와 유발 표현의 쓰임을 회상합니다.
- 문형·구조의 ‘동사 문형 섞어 복습’은 2·4·5형식, that절, to V·목적어 + to V·V-ing를 섞어 세부 범위로 답을 추측하기 어렵게 합니다. 별도 중복 카드를 만들지 않습니다.

`memory-practice.js`는 기존 카드 ID별 단계 패치와 빠진 쓰임의 신규 카드만 담습니다. 기존 원본 두 문제 파일과 두 보기 파일, 분류 파일은 바이트 단위로 보존합니다. 같은 카드의 단계 수와 정답 인덱스도 유지하며, 새 버전에 한해서만 문장·보기를 적용합니다. 전치사/to부정사 선택 이외에도 역방향 단어 선택에 맞게 단계 연결 여부를 별도 지정합니다.

여러 구조를 모두 허용하는 단어는 한 구조만 가능하다고 가르치지 않습니다. try·prefer 등의 중복 허용이나 기억하다/잊다의 의미 차이는 정답이 하나로 정해지는 문맥·보기로 처리합니다. 비교 강조어 much·even·far처럼 모두 가능한 표현끼리를 단일 정답의 경쟁 보기로 놓지 않습니다. 교재 밖의 일반 문법 전 범위로 확대하지 않으며, 인쇄된 목록에 근거한 응용 문장으로 연습합니다.

큰 분류는 문형·구조 / Collocation · 어휘 결합 / 어형·수식 / 시제·시간 표현 / 문장 연결 / 의미 구별·재표현의 6개입니다. 문형·구조에는 동사의 목적어·보어, 자동사+전치사, that절, to부정사·동명사를 모읍니다. `depend on`은 문형·구조에 둡니다. 단어끼리의 결합은 Collocation에, 복합명사는 어형·수식에, 다의어와 다품사어는 의미 구별·재표현에 둡니다. 동사+that절은 요청·권고 여부로 추가 분할하지 않습니다.

분류는 `taxonomy.js`에서 정답 학습 대상과 기존 출처에 따라 연결합니다. `questions.js`를 수정하거나 분류 속성을 붙이지 않으므로 기존 문제 서명은 유지됩니다. 여러 주제가 섞였던 LC/RC 범위는 표현별로 재분류합니다. 이전 STEP·15개 범위 저장값은 새 분류로 연결하고, 주제가 혼합된 옛 LC/RC 선택값만 전체 범위로 연결합니다. 진행 중인 기존 풀이·선택한 답·보기 순서·누적 기록은 바꾸지 않습니다. 큰 분류·세부 범위는 기존 `settings.step` 필드 하나로 저장하여 이전 계정·백업 형식을 유지합니다.

퀵스타트 추가 741문제는 문형·구조 331개, Collocation 78개, 어형·수식 128개, 시제·시간 표현 33개, 문장 연결 140개, 의미 구별·재표현 31개입니다. 일부 기존 카드는 뜻 중심이지만, 신규 문형 문제는 목적어·보어·전치사·동사 형태 등을 직접 선택합니다. 뜻만 맞히는 카드로 문법 목록을 대체하지 않습니다.

`quickstart.js`는 추가 문제와 외부 출처 연결만 포함합니다. 원본 카드에 출처나 분류 속성을 덧붙이지 않고 목록을 별도의 배열로 합치므로 기존 서명·답·보기 순서가 바뀌지 않습니다. `sync-model.js`는 새 문제 버전의 첫 단계 종료 상태만 추가 허용하며, 기존 저장 형식과 버전 검증은 유지합니다. 게시된 신규 문제 역시 저장된 풀이의 서명에 포함되므로 이후 내용을 고칠 때는 기존 카드 보존과 버전 처리가 필요합니다.

## 기록과 기존 사이트

기존 토익 사이트의 `power-voca/` 교재 메뉴로 연결하는 버전입니다. 사이트에서 같은 Google 계정으로 로그인하면 교재 누적 기록과 최근 이어 풀기를 자동으로 연결합니다. 이미 열어 둔 문제와 선택한 답은 다른 기기의 진행 때문에 바뀌지 않습니다. 첫 진입·새로고침 시 시작 화면에서 ‘이어서 풀기’를 눌러 진행합니다.

교재 기록은 기존 단어장·랜덤 문제집과 다른 전용 문서에 저장합니다. 기존 두 메뉴의 학습 데이터는 바꾸지 않습니다. 로그인 전 기기 기록과 계정별 임시 기록도 분리 보관합니다.

`file://`로 직접 열거나 로그인하지 않은 경우에는 기기·브라우저 저장만 사용합니다. 로컬 파일 미리보기에서 이미 공부한 기록은 시작 화면의 ‘백업과 기록 가져오기’ → ‘교재 기록 백업’으로 내보낸 뒤 사이트의 같은 메뉴에서 가져오세요. 파일 주소와 사이트 주소의 저장 공간은 브라우저 보안상 자동으로 공유되지 않습니다. 가져오기는 현재 기록을 먼저 백업하고, 같은 기록의 횟수를 중복으로 더하지 않습니다.

브라우저 데이터 삭제·비공개 창 종료·다른 브라우저 사용 시 아직 계정에 저장되지 않은 기록은 없어질 수 있습니다. 다른 기기로 이동하기 전 ‘계정 저장 확인됨’ 상태를 확인하세요.

## 출제 시 주의한 부분

인쇄된 유사 표현을 모든 문장에서 교체 가능한 동의어로 취급하지 않았습니다. 문맥이 없으면 오해가 생기는 일부 쌍은 유의어 선택 문제에서 제외하고 해설에만 남겼습니다. 서로 겹치는 뜻을 오답으로 배치하지 않도록 별도 제외 규칙과 문맥 보완을 적용했습니다.

교재의 `recommended me that` 같은 비표준 구조는 그대로 재사용하지 않았습니다. `dues`처럼 해당 의미에 맞는 표기를 사용했고, `on installment`는 교재 표기임을 해설에서 구분하며 전치사 정답을 강제하지 않았습니다. 검토가 필요한 일부 반대말 묶음은 오답·정답으로 쓰지 않았습니다.
