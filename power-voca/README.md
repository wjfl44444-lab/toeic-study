# 파워토익 VOCA

교재 STEP 1~30의 표제어 1,015개와 인쇄된 추가 표현 693개를 바탕으로 만든 개인 학습용 객관식 2,282문제입니다. 손글씨 필기는 제외했습니다.

표현 완성 → 뜻, 뜻 → 유사 표현 순서로 익히고, 두 단계 선택을 마친 뒤 정답과 해설을 확인합니다. 다의어는 문맥별로 나누었으며 일부 문제는 표현이나 문법 패턴 자체를 완성합니다.

같은 Google 계정으로 교재 학습 기록과 최근 이어 풀기를 연결합니다. 기존 단어장·랜덤 문제집 기록과는 별도 공간에 보관하며, 다른 기기가 이미 열어 둔 문제와 선택한 답을 바꾸지 않습니다.

로컬 파일에서 공부한 기록은 교재 시작 화면의 ‘백업과 기록 가져오기’로 옮길 수 있습니다.
