# 표현·구조 훈련

기존 파워토익 VOCA 문제를 교재 구분 없이 학습 목표에 따라 모으는 메뉴입니다. 기존 주소와 기록 저장 공간은 유지합니다. `index.html`, `styles.css`, `questions.js`, `practice-options.js`, `practice-options-hard.js`, `taxonomy.js`, `app.js`는 같은 폴더에 보관하세요.

[계정 동기화가 연결된 사이트에서 열기](https://wjfl44444-lab.github.io/toeic-study/power-voca/). 파일로 보관할 때는 `sync-model.js`도 같은 폴더에 두세요.

## 학습 범위

사용자가 제공한 「박혜원 파워토익 VOCA」의 STEP 1~30, 번호 0001~1015 전체를 반영했습니다. 인쇄된 추가 표현 693개를 포함하며, 손글씨 필기는 제외했습니다.

- 표제어: 1,015개
- 추가 표현: 693개
- 다의어·품사를 나눈 학습 대상: 총 2,001개
- 객관식 카드: 2,282개, 선택 단계 총 3,475개
- 두 단계 카드: 1,193개

같은 표제어도 뜻·품사·유사 표현에 따라 여러 카드가 될 수 있으므로 카드 수와 단어 수는 다릅니다. 문맥이 필요한 다의어에는 새 예문과 해석을 넣었습니다. 일부 결합 문제는 문장 대신 표현이나 문법 패턴 자체를 완성합니다. 형용사·부사나 동사의 목적어 구조를 구별하는 어형 복습도 포함됩니다.

## 사용 방법

1. 큰 분류와 세부 범위를 고른 뒤 20·50·100문제 또는 전체 문제를 선택합니다. 현재 등록되지 않은 세부 범위는 0문제로 표시하며 시작할 수 없습니다.
2. 표현 결합은 표현 완성 → 뜻, 유사 표현은 뜻 → 유사 표현 순서로 풉니다.
3. 두 단계 문제의 첫 답은 ‘답 확인’을 눌러 확인합니다. 틀리면 그 문제를 바로 오답 처리하고 해설을 보여줍니다. 맞히면 두 번째 단계로 넘어갑니다. 표현 결합 문제에서는 완성된 영어 표현을 보고 뜻을 고릅니다.
4. 채점 후 큰 글씨로 완성 표현과 뜻을 먼저 보여주고, 그 아래에 단계별 해석·선택지 설명을 제공합니다.
5. 새로고침하면 시작 화면이 열립니다. 저장된 풀이의 ‘이어서 풀기’를 누르면 선택지 순서와 선택한 답까지 복원합니다.

첫 단계에서 종료한 문제의 두 번째 단계는 ‘미진행’으로 표시하며, 추가 오답이나 채점 횟수로 세지 않습니다. 뜻 선택지는 같은 품사·문장형끼리 비교하도록 구성하고, 결합 표현은 가능한 경우 공통된 명사·내용의 해석을 유지한 채 다른 부분을 비교합니다.

개선된 뜻 선택지는 새 연습부터 적용됩니다. 저장된 풀이도 아직 바뀌는 뜻 보기에는 답하지 않았고 채점한 카드가 없으면 새 선택지로 안전하게 연결합니다. 이미 뜻을 선택하거나 채점한 풀이는 선택한 답의 의미가 바뀌지 않도록 이전 선택지를 그대로 복원합니다. 이전 풀이에서도 첫 단계 오답 시 즉시 종료하는 진행 방식은 적용됩니다. 원본 문제와 누적 기록은 유지하고, 새 연습의 선택지 버전을 별도로 저장합니다.

유지보수 시 게시된 선택지 버전의 내용은 바꾸지 않습니다. 이후 선택지를 수정하려면 새 버전을 부여하고 이전 버전의 선택지도 보존해야 이미 선택한 답의 의미가 바뀌지 않습니다.

영어 보기 개선판(`20261019-hard2`)은 교재에 나오는 짝표현·유사 표현을 기준으로 답을 고릅니다. 기존 문제 문장은 유지하고, 같은 품사와 비슷한 표현 구조 안에서 정답을 구별하도록 보기를 구성합니다. 다른 보기가 모든 문맥에서 문법적으로 불가능하다는 뜻은 아닙니다. 반복되던 자동사 묶음이나, 명사구와 단독 형용사·동사구를 섞어 정답 형태가 드러나는 오답을 교체합니다.

기존 `20261019-linked1` 선택지 파일은 그대로 보존합니다. 이미 답을 고르거나 채점한 저장 풀이는 이전 보기 버전으로 계속 복원하고, 새 연습은 개선판을 사용합니다. 모든 바뀌는 보기가 아직 미응답인 이전 풀이는 선택한 답의 뜻이나 순서를 바꾸지 않고 개선판으로 연결할 수 있습니다.

큰 분류는 문형·구조 / Collocation · 어휘 결합 / 어형·수식 / 시제·시간 표현 / 문장 연결 / 의미 구별·재표현의 6개입니다. 문형·구조에는 동사의 목적어·보어, 자동사+전치사, that절, to부정사·동명사를 모읍니다. `depend on`은 문형·구조에 둡니다. 단어끼리의 결합은 Collocation에, 복합명사는 어형·수식에, 다의어와 다품사어는 의미 구별·재표현에 둡니다. 동사+that절은 요청·권고 여부로 추가 분할하지 않습니다.

분류는 `taxonomy.js`에서 정답 학습 대상과 기존 출처에 따라 연결합니다. `questions.js`를 수정하거나 분류 속성을 붙이지 않으므로 기존 문제 서명은 유지됩니다. 여러 주제가 섞였던 LC/RC 범위는 표현별로 재분류합니다. 이전 STEP·15개 범위 저장값은 새 분류로 연결하고, 주제가 혼합된 옛 LC/RC 선택값만 전체 범위로 연결합니다. 진행 중인 기존 풀이·선택한 답·보기 순서·누적 기록은 바꾸지 않습니다. 큰 분류·세부 범위는 기존 `settings.step` 필드 하나로 저장하여 이전 계정·백업 형식을 유지합니다.

이번 변경은 기존 2,282문제의 분류와 탐색 화면 정리입니다. 퀵스타트의 새로운 문제를 추가한 것은 아닙니다. 일부 범위에는 기존 뜻 중심 카드가 포함되며, 분류만 바꿨다고 모든 카드가 문법 형태 선택 문제로 바뀌지는 않습니다.

## 기록과 기존 사이트

기존 토익 사이트의 `power-voca/` 교재 메뉴로 연결하는 버전입니다. 사이트에서 같은 Google 계정으로 로그인하면 교재 누적 기록과 최근 이어 풀기를 자동으로 연결합니다. 이미 열어 둔 문제와 선택한 답은 다른 기기의 진행 때문에 바뀌지 않습니다. 첫 진입·새로고침 시 시작 화면에서 ‘이어서 풀기’를 눌러 진행합니다.

교재 기록은 기존 단어장·랜덤 문제집과 다른 전용 문서에 저장합니다. 기존 두 메뉴의 학습 데이터는 바꾸지 않습니다. 로그인 전 기기 기록과 계정별 임시 기록도 분리 보관합니다.

`file://`로 직접 열거나 로그인하지 않은 경우에는 기기·브라우저 저장만 사용합니다. 로컬 파일 미리보기에서 이미 공부한 기록은 시작 화면의 ‘백업과 기록 가져오기’ → ‘교재 기록 백업’으로 내보낸 뒤 사이트의 같은 메뉴에서 가져오세요. 파일 주소와 사이트 주소의 저장 공간은 브라우저 보안상 자동으로 공유되지 않습니다. 가져오기는 현재 기록을 먼저 백업하고, 같은 기록의 횟수를 중복으로 더하지 않습니다.

브라우저 데이터 삭제·비공개 창 종료·다른 브라우저 사용 시 아직 계정에 저장되지 않은 기록은 없어질 수 있습니다. 다른 기기로 이동하기 전 ‘계정 저장 확인됨’ 상태를 확인하세요.

## 출제 시 주의한 부분

인쇄된 유사 표현을 모든 문장에서 교체 가능한 동의어로 취급하지 않았습니다. 문맥이 없으면 오해가 생기는 일부 쌍은 유의어 선택 문제에서 제외하고 해설에만 남겼습니다. 서로 겹치는 뜻을 오답으로 배치하지 않도록 별도 제외 규칙과 문맥 보완을 적용했습니다.

교재의 `recommended me that` 같은 비표준 구조는 그대로 재사용하지 않았습니다. `dues`처럼 해당 의미에 맞는 표기를 사용했고, `on installment`는 교재 표기임을 해설에서 구분하며 전치사 정답을 강제하지 않았습니다. 검토가 필요한 일부 반대말 묶음은 오답·정답으로 쓰지 않았습니다.

표기 검토 참고: [Cambridge Dictionary — installment](https://dictionary.cambridge.org/us/dictionary/english/installment), [installment plan](https://dictionary.cambridge.org/us/dictionary/english/installment-plan), [out of the question](https://dictionary.cambridge.org/dictionary/english/out-of-the-question). 외부 사전의 예문은 문제에 복사하지 않았습니다.
